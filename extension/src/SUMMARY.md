# extension/src

- `background/` — service-worker modules: connection, routing, validation
- `content/` — content-script modules: relay and announcement
- `entrypoints/` — WXT entrypoints wiring the modules
- `generated/` — files generated by `cargo xtask gen`; do not edit
- `popup/` — popup state and rendering
- `shared/` — helpers shared by background and popup
