For developers

Add signing to your website or your desktop program. You build the document and its hash; WebeSign returns the signature and the certificate.

Website: @websign/sdk

TypeScript, zero dependencies, under 5 KB. Call sign() with a prepare function that returns the hash of the signed attributes.

import { sign } from "@websign/sdk";
const result = await sign({
  hash: "SHA-256",
  prepare: async (certificate, { algorithm }) => digestOfSignedAttributes(certificate, algorithm),
});

Desktop program (Node, Bun, Electron): @websign/desktop

Connect to the app, then call sign(). The app names your program in its confirmation window.

import { WebSign } from "@websign/desktop";
const websign = await WebSign.connect();
const { signature, certificate } = await websign.sign({
  hash: "SHA-256",
  prepare: async (cert, algorithm) => digestFor(cert.der, algorithm),
});
await websign.close();

Desktop program (Rust): websign-client

Client::connect(), then certificates() or sign(). The app is started on demand.
