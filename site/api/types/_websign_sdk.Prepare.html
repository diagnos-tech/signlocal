    Prepare: (
        certificate: Certificate,
        context: PrepareContext<H, A>,
    ) => Bytes | Promise<Bytes>

    Returns the digest to sign with certificate: exactly DigestLength bytes for the hash. May run more than once if the person switches certificate; only the last digest is signed. Throwing aborts the request.
