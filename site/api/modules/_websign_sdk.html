    Module @websign/sdk

    @websign/sdk — sign with the visitor's certificate (smart card, USB token or a certificate installed on the computer) from a web page.

    The page never talks to the app: it posts messages to the WebeSign extension, which adds the page's origin as the browser reports it and forwards them to the app over native messaging. The person confirms every signature in the app's own window.

    Example

    import { sign } from "@websign/sdk";

    const { signature, certificate } = await sign({
      hash: "SHA-256",
      prepare: (certificate, { hash }) => crypto.subtle.digest(hash, signedAttributesFor(certificate)),
    });
