Download WebeSign

Install the app and the browser extension. Both are needed.

Prerelease builds are not code-signed yet

Windows shows SmartScreen and macOS shows Gatekeeper the first time. The steps below say what to click. Code signing is planned. Always check the SHA256SUMS file.

The repository is private for now, so downloads need the GitHub CLI signed in (gh auth login).

While the repository is private

gh auth login
gh release download v<v> --repo diagnos-tech/web-esign --pattern install.sh --pattern SHA256SUMS

Windows

Run the installer script. If you unzip and run websign.exe by hand and SmartScreen appears, choose More info, then Run anyway.

gh release download v<v> --repo diagnos-tech/web-esign --pattern install.ps1 --pattern SHA256SUMS
# verify install.ps1 against SHA256SUMS (docs/install.md), then:
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Version <v>

Once the repository is public:

Invoke-WebRequest -UseBasicParsing -Uri https://github.com/diagnos-tech/web-esign/releases/download/v<v>/install.ps1 -OutFile install.ps1
Invoke-WebRequest -UseBasicParsing -Uri https://github.com/diagnos-tech/web-esign/releases/download/v<v>/SHA256SUMS -OutFile SHA256SUMS

macOS

Run the installer script. If you installed by hand and macOS blocks the app, open System Settings, Privacy & Security, and click Open Anyway, or run the xattr command below. Notarization is pending.

gh release download v<v> --repo diagnos-tech/web-esign --pattern install.sh --pattern SHA256SUMS
shasum -a 256 --ignore-missing -c SHA256SUMS && sh install.sh --version <v>
# only if you installed by hand:
xattr -dr com.apple.quarantine /Applications/WebeSign.app

Once the repository is public:

curl -fsSLO https://github.com/diagnos-tech/web-esign/releases/download/v<v>/install.sh
curl -fsSLO https://github.com/diagnos-tech/web-esign/releases/download/v<v>/SHA256SUMS
shasum -a 256 --ignore-missing -c SHA256SUMS && sh install.sh --version <v>

Linux

Use the .deb (Ubuntu 22.04 and 24.04, Debian 12), the .rpm (Fedora 42, Rocky 9), or the script and tar.gz for Arch and others.

# any distribution, per user
sha256sum --ignore-missing -c SHA256SUMS && sh install.sh --version <v>
# Ubuntu, Debian
sha256sum --ignore-missing -c SHA256SUMS && sudo apt install ./websign_<v>_amd64.deb
# Fedora, Rocky Linux 9
sha256sum --ignore-missing -c SHA256SUMS && sudo dnf install ./websign-<v>-1.x86_64.rpm

Browser extension

Chrome, Edge and Brave: load the unzipped extension from the extensions page in developer mode. Firefox: load it as a temporary add-on until it is signed. Safari comes later.

Check every download

Each release has a SHA256SUMS file. Compare the hash of your file with its line. The installer scripts do this for you.

sha256sum --ignore-missing -c SHA256SUMS
