# assets

- `tokens.css` — design tokens mirroring docs/ux.md §11 (light and dark)
- `site.css` — layout and components, mobile first
- `home.css` — landing page: hero, how-it-works flow, badges, FAQ
- `download.css` — download page: numbered steps, tabs, tables
- `i18n.js` — language detection, saved choice, text and aria-label swap
- `detect.js` — guesses the visitor's OS and browser (nothing is sent)
- `cta.js` — "Download for <OS>" button and the phone hint
- `tabs.js` — accessible tabs, opened from the URL hash or the detected OS/browser
- `icon.svg` — site icon
- `websign-sdk.js` — built `@websign/sdk` ESM bundle plus error texts (generated by `../build-sdk.sh`; do not edit)
- `test-page.js` — behavior of the test-signature page
- `test-crypto.js` — certificate key extraction and WebCrypto signature check (pure, unit-tested)
- `test.css` — styles of the test page
