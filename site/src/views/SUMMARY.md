# site/src/views

One component per page; the root route and the `[lang]` route both render it.

- `ActivateView.astro` — finish setting up
- `CompatibilityView.astro` — compatibility
- `DevelopersView.astro` — for developers (English)
- `HelpView.astro` — help and the full FAQ
- `HomeView.astro` — home
- `InstallView.astro` — the install wizard page
- `NoticesView.astro` — licenses and trademarks (English)
- `PrivacyView.astro` — privacy
- `TestView.astro` — test your setup
