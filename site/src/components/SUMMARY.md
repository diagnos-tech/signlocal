# site/src/components

Astro components, one folder per area. Styles are scoped to each component; colours come from the design tokens.

- `brand/` — the mark and the wordmark
- `compatibility/` — the compatibility page's sections
- `developers/` — the developers page's pieces
- `home/` — the home page's sections
- `layout/` — head, headers, footer, language menu
- `result/` — the cards of the wizard's result step
- `test/` — the three cards of the test page
- `ui/` — buttons, icons, callouts, command blocks, file cards, disclosures, tabs
- `wizard/` — the wizard card, its steps, tiles and progress indicator
