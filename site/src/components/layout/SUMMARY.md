# site/src/components/layout

The frame of a page.

- `DevHeader.astro` — the developers pages' header
- `Footer.astro` — three columns and the language menu
- `Head.astro` — everything in <head>, in order, including the Content-Security-Policy
- `Header.astro` — the sticky header with a menu disclosure on narrow screens
- `LanguageMenu.astro` — the language menu: a disclosure of links to the same page in each language
- `SampleDataRibbon.astro` — the "sample release data" ribbon shown by local builds
- `SkipLink.astro` — the skip-to-content link
