# site/src/components/wizard

The install wizard's card and its four steps.

- `DeviceNotice.astro` — the phone and Chromebook notices
- `Segmented.astro` — a radio group as a segmented control (the processor)
- `StepBrowser.astro` — step 2: which browser
- `StepCertificate.astro` — step 3: where the certificate is
- `Stepper.astro` — the progress indicator
- `StepResult.astro` — step 4: the checklist for this computer
- `StepSystem.astro` — step 1: which system, processor and distribution
- `Tile.astro` — a radio card with icon, label, caption and Detected pill
- `Wizard.astro` — the card: stepper, steps, navigation and the data the browser code reads
- `WizardNav.astro` — Back and Next
