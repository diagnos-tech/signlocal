# site/src/components/home

Sections of the home page.

- `Faq.astro` — the questions, all or the six the home page shows
- `FinalCta.astro` — the closing call to action
- `Hero.astro` — the promise, the calls to action and the start card
- `HowItWorks.astro` — the four parties of a signature and the confirmation window
- `Promises.astro` — the four promises
- `StartCard.astro` — the three system tiles that start the install
- `WindowMock.astro` — an illustration of the signlocal confirmation window
- `WorksWith.astro` — systems and browsers with their minimum versions
