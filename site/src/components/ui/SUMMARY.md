# site/src/components/ui

General-purpose building blocks.

- `BrowserLogo.astro` — a browser's logo as an image (or the generic browsers icon)
- `BrowserText.astro` — a sentence naming the browser, one variant per browser plus a no-script fallback
- `Button.astro` — primary, secondary and link buttons, as links or buttons
- `Callout.astro` — info, warning and success boxes
- `Chip.astro` — status pills
- `ClientStrings.astro` — the JSON block of texts a client module reads
- `CommandBlock.astro` — a dark block for commands and code, with its Copy button
- `CopyButton.astro` — copies the text of another element
- `Disclosure.astro` — a native details/summary, as a card or a quiet link
- `FileCard.astro` — a download: name, size, SHA-256, the Download button and the optional check
- `Icon.astro` — an inline Phosphor icon
- `OsMark.astro` — Windows, macOS and Linux marks in their colours
- `Tabs.astro` — the tab list of an ARIA tabs control
