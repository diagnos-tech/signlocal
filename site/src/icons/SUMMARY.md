# site/src/icons

Icons from `@phosphor-icons/core` 2.1.1 (MIT), copied unmodified from the npm package (`assets/regular` and `assets/fill`) and inlined by `components/ui/Icon.astro`.

- `LICENSE-Phosphor.txt` — the package's licence text (MIT)
- `os/` — Windows, Apple and Linux marks (fill weight)
- `ui/` — interface icons (regular weight; `-fill` files are the fill weight)
