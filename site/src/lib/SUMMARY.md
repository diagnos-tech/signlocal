# site/src/lib

Helpers used while building pages.

- `browsers.ts` — how a browser is named in a sentence
- `data-types.ts` — the shapes of the generated JSON
- `devices.ts` — the tokens and cards from devices.json
- `error-codes.ts` — the SDK's error codes
- `format.ts` — sizes and dates in the visitor's language
- `icons.ts` — loads the icon SVGs
- `meta.ts` — the message keys of each page's title and description
- `paths.ts` — getStaticPaths of the language routes
- `release-files.ts` — finds a file of the release or fails the build
- `routes.ts` — page ids → addresses, language alternates, link resolution for messages
- `site.ts` — typed access to the generated data
- `svg.ts` — prepares an icon's SVG for inlining
- `translate.ts` — the translator and rich-text renderer of a language
