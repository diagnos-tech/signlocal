# app

- `assets/` — embedded fonts and icons with their licenses (OFL-1.1, MIT)
- `src/` — sources of the `websign` binary
- `tests/` — tests of the built binary: CLI contract, SoftHSM2 through `connect`, no e2e hook in releases
- `Cargo.toml` — the `websign` binary's manifest and features (`e2e`)
- `README.md` — what this component is, how to build and test it, where its contract lives
