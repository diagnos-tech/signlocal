@signlocal/sdk examples

Each example runs on the SDK's testing fake, so it works without the extension. Add ?real to the address to use the real signlocal extension and app.

  • Vanilla HTML: one file, no framework.
  • React: a useSignlocal() hook.
  • Vue: a useSignlocal() composable.
  • PAdES: sign a PDF with pdf-lib and PKI.js.
