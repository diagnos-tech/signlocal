# e2e/lib/firefox

- `bidi.ts` — A minimal WebDriver BiDi client over Node's WebSocket: commands and replies.
- `launch.ts` — Firefox in a throwaway profile, the extension as a temporary add-on, the app registered as a person's install does.
- `tab.ts` — One Firefox tab with the `evaluate` the fixture calls use, and screenshots.
- `values.ts` — JSON values to and from BiDi's typed form.
