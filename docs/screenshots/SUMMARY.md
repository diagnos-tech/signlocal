# docs/screenshots

Window screenshots per operating system, collected from e2e runs by `cargo xtask screenshots`.

- `archlinux/` — every window state on archlinux, light and dark
- `debian-12/` — every window state on debian-12, light and dark
- `fedora-42/` — every window state on fedora-42, light and dark
- `macos/` — every window state on macos, light and dark
- `popup/` — every extension popup state, light and dark, and the missing state in 7 locales
- `rockylinux-9/` — every window state on rockylinux-9, light and dark
- `ubuntu-22.04/` — every window state on ubuntu-22.04, light and dark
- `ubuntu-24.04/` — every window state on ubuntu-24.04, light and dark
- `windows/` — every window state on windows, light and dark
