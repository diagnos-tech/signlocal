# probe/src/commands

Subcommands that work across all key sources.

- `list.rs` — `list`: prints every signing certificate by source
- `mod.rs` — module declarations
- `report.rs` — `report`: one Markdown file with everything a proof needs and nothing personal
- `sign.rs` — `sign`: signs random digests and verifies every signature
- `view.rs` — how keys and certificates are described in command output
