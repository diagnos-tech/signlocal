WebeSign UI Mockups

Mockups for the docs/ux.md specification, for approval. Fictitious data. The UI ships in 7 languages (en, es, pt-PT, pt-BR, fr, it, de); these mockups show the Brazilian Portuguese (pt-BR) copy of the app UI, while the page text around it is English.

Confirmation window

480 × 600 logical px, fixed, on top, centered on the pointer's monitor. It appears on every signature. The site comes from the browser; the verification code comes from the digest; no text from the site gets in here.

Diagnostics window

760 × 540 logical px. Opens from the app icon, from the popup, and from errors. The tabs really switch; each one has a traffic light with color, shape, and text. Scenario: Windows, new token without a driver, certificates about to expire.

Getting started (strip at the top of the content, first run only)

It goes away when everything turns green and the first test signature passes, or when the user hides it.

Extension popup

320 px wide, plain TS + CSS, under 15 KB. System font so it looks like part of the browser. “App installed but never opened” falls into “Not installed” and is resolved with “Already installed? Activate the app”, which opens the /ativar page and calls the websign: scheme.
