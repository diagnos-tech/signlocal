# docs

- `architecture/` — contracts: overview, protocol, web and desktop APIs, security, i18n, testing, packaging, layout, platform floors
- `prototypes/` — risk proofs per OS (answer, evidence, decision) and the kit that produced them
- `research/` — sourced research on native messaging, PKCS#11 modules and tokens
- `screenshots/` — Window screenshots per OS, collected from e2e runs by `cargo xtask screenshots`
- `ux/` — light and dark HTML mockups of the windows and the popup
- `compatibility.md` — tested token, OS and browser matrix, and how testers report with `websign doctor --json`
- `install.md` — Install and uninstall per OS for the unsigned prerelease, extension steps, checksum verification
- `plan.md` — decisions, tracks, and what remains
- `ux.md` — UX/UI specification: windows, popup, texts, tokens, accessibility
