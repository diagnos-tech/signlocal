# docs

Documentation of the project: plan, architecture, UX specification, and the research and risk proofs behind the decisions.

- `architecture/` — architecture documents of the product (written and maintained by the architecture track)
- `compatibility.md` — matrix of manual test results with real tokens, cards, and browsers; CI only covers software keys
- `plan.md` — the approved implementation plan
- `prototypes/` — risk proofs per operating system, with the evidence and the kit code that produced it
- `research/` — sourced research on tokens, PKCS#11 module paths, and native messaging registration
- `ux.md` — the full UX/UI specification: windows, copy, design tokens, accessibility, errors, test cases
- `ux/` — navigable HTML mockups that implement the tokens of `ux.md`
