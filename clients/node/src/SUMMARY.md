# clients/node/src

- `generated/` — files generated by `cargo xtask gen`; do not edit
- `client.ts` — One connection to the app.
- `errors.ts` — `WebSignError`: failures with the protocol's stable codes
- `framing.ts` — 4-byte little-endian length + UTF-8 JSON, like native messaging.
- `index.ts` — @websign/desktop — call the WebeSign app from a desktop program.
- `locate.ts` — The `websign` executable: `WEBSIGN_EXECUTABLE`, else `websign` on PATH, else the install locations of docs/architecture/packaging-and-release.md §Install locations.
