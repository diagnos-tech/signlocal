# websign-registration

Makes browsers find the app: native messaging manifests for Chrome, Edge,
Brave, Chromium, Vivaldi, Opera and Firefox on every OS (per user, and
system-wide for Linux packages), the `websign:` URL scheme, extension
pre-registration on Windows, installed-browser detection and read-back status
for diagnostics.

- Manifest writing per OS is promoted from the Phase-0 kit (proven in CI,
  inside the macOS sandbox and from an MSIX package).
