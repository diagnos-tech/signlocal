# websign-core

Pure signing logic shared by every part of the app: hash and signature
algorithm names, `DigestInfo`, ECDSA DER ↔ raw conversion, the tolerant
X.509 summary (ICP-Brasil and eIDAS profiles), signature verification,
de-duplication by fingerprint, and the display rules of the confirmation
window (`present`: origin, holder name, masked document, desktop caller,
wire mappings). No OS calls.

- Contract: [`SPEC.md`](SPEC.md) — §1–§8 promoted from the Phase-0 kit's
  `probe-core` (391 tests, reviewed); §4.1, §6.1a and §9–§13 added by a
  second blind-TDD round and reconciled.
- Tests: `cargo test -p websign-core` (fixtures generated by OpenSSL in
  [`tests/fixtures`](tests/fixtures/)).
