# sdk/src

- `certificates.ts` — `certificates()`: the certificate the person chooses
- `change.ts` — `onChange()`: status change notifications
- `channel.ts` — internal: page side of the page ↔ extension protocol (discover, send, follow-ups, subscribers)
- `convert.ts` — wire ↔ public conversions: strict Base64 ↔ bytes, Unix seconds ↔ Date
- `digest.ts` — the digest step of `sign()`: need_digest cross-check and `prepare` result checks
- `errors.ts` — `WebSignError`, the catalog guard (unknown codes → Internal) and shared rejections
- `fingerprint.ts` — `fingerprint()`: the verification code, identical to the app's
- `generated/` — files generated by `cargo xtask gen`; do not edit
- `incoming.ts` — strict validation of messages arriving on `window`
- `index.ts` — the public entry point (channel internals are not exported)
- `install.ts` — `installUrl()`: the store of this browser or the download page
- `messages.gen.ts` — generated error texts per locale (from i18n/*.toml `[site.errors]`)
- `messages.ts` — `@websign/sdk/messages`: `errorText()` in the closest shipped locale
- `project.ts` — the project.toml values the SDK needs (store IDs, homepage)
- `request.ts` — connect (abortable discovery, protocol check), ask, and reply conversion guard
- `sign.ts` — `sign()`: one signature with `prepare(certificate)`
- `status.ts` — `status()`: extension and app state without any window
- `types.ts` — public types of the SDK
- `validate.ts` — checks of hash, algorithm and certificate options before anything is sent
