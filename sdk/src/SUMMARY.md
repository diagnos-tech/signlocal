# sdk/src

- `generated/` — files generated by `cargo xtask gen`; do not edit
- `certificates.ts` — `certificates()`: the certificate the person chooses
- `change.ts` — `onChange()`: status change notifications
- `channel.ts` — The page side of the page ↔ extension protocol (window.postMessage).
- `convert.ts` — Wire ↔ public conversions: Base64 ↔ bytes, Unix seconds ↔ Date.
- `errors.ts` — Typed errors: every rejection of the SDK is a {@link WebSignError}.
- `fingerprint.ts` — `fingerprint()`: the verification code, identical to the app's
- `index.ts` — @websign/sdk — sign with the user's certificate from a web page.
- `install.ts` — Where to send a person who lacks the extension: the store of the current browser (Chrome Web Store, Edge Add-ons, Firefox AMO; Safari → the app's download page), or the project's download page when unknown.
- `messages.ts` — @websign/sdk/messages — user-facing texts for SDK error codes, in the shipped locales (generated from i18n/*.toml `[site.errors]`).
- `sign.ts` — `sign()`: one signature with `prepare(certificate)`
- `status.ts` — `status()`: extension and app state without any window
- `types.ts` — Public types of the SDK.
